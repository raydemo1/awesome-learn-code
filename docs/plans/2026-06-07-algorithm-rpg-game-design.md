# 算法打怪 RPG - Web端产品设计方案

## 1. 产品概述 (Overview)
本产品是一款面向计算机专业学生、程序员及算法爱好者的**像素风打怪RPG Web 网页游戏**。
通过 PaddleOCR 识别用户上传的算法题（如 LeetCode 截图），利用大语言模型将其智能拆解为“回合制状态预测”的战斗关卡。玩家需要通过判断算法每一步的正确状态来对怪兽造成伤害，在游戏化的反馈中真正掌握算法运行逻辑。

## 2. 核心玩法机制 (Gameplay)
- **战斗逻辑**：一道算法题 = 一个 Boss 战。算法的每一个关键迭代步 = 一个回合。
- **攻击方式**：玩家通过预测数据结构的下一步状态（如“两个指针分别指向哪”、“临时变量的值”），选择正确则发起攻击，选择错误则受到怪兽攻击。
- **体力/法力值**：对应算法的**时间复杂度**。如果玩家选择暴力的步骤（比如多重嵌套循环的选项），会急剧消耗体力，可能在打败 Boss 前力竭。
- **背包/护盾**：对应算法的**空间复杂度**。

## 3. Web 端 UI 架构设计 (UI/UX)
充分利用 Web 宽屏的优势，采用 **“左右分栏 + 下方控制”** 的布局：

- **左侧区域（游戏视觉区 40% 宽度）**：
  - 展示像素风角色与怪兽对战的动画。
  - 显示怪兽血条（剩余解题步骤数）、玩家血条（容错率）、体力槽（时间复杂度限制）。
- **右侧区域（算法视界区 60% 宽度）**：
  - **可视化面板**：动态渲染当前的数据结构状态（数组、链表、树、图的节点变化）。
  - **代码区**：高亮显示当前执行到的代码行或伪代码块。
- **下方区域（操作控制台）**：
  - **选项区**：给出 2-4 个关于“下一步状态”的选择。
  - **战斗日志**：答错时怪兽的嘲讽与 AI 辅导提示（例如：“你忘记处理边界条件了！受到 20 点伤害！”）。

## 4. 系统数据流与 AI 拆解架构
1. **用户输入**：在网页端上传题目截图 / 粘贴文本。
2. **OCR 提取**：调用 PaddleOCR / Tesseract 提取文本。
3. **AI 关卡生成 (核心)**：通过 Prompt 让大模型将题目转化为标准 JSON 格式：
   ```json
   {
     "monster_name": "混乱双指针巨魔",
     "total_steps": 5,
     "steps": [
       {
         "step_id": 1,
         "description": "循环第一步",
         "visual_state": {"array": [2,7,11,15], "pointer_left": 0, "pointer_right": 3},
         "question": "下一步 right 指针应该如何移动？",
         "options": [
           {"id": "A", "text": "right - 1", "is_correct": true, "damage": 20},
           {"id": "B", "text": "left + 1", "is_correct": false, "feedback": "当前和过大，应该移动右指针减小总和！"}
         ]
       }
     ]
   }
   ```
4. **引擎渲染**：前端解析 JSON，驱动游戏画面和状态的可视化更新。

## 5. 技术栈推荐
- **前端框架**：React / Next.js / Vue3（用于构建复杂的 UI 和状态管理）
- **游戏/可视化渲染**：
  - 游戏画面：PixiJS 或简单的 CSS 动画（像素风对性能要求不高）。
  - 数据可视化：D3.js 或 React Flow（用于画树、图、链表）。
- **后端服务**：Node.js (Express/NestJS) 或 Python (FastAPI，更适合对接深度学习模型)。
- **AI / OCR**：PaddleOCR API + 任意主流大模型 API（如 DeepSeek-Coder, GPT-4o, Claude-3.5-Sonnet）。
